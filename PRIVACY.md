# Privacy Policy – PortKill

PortKill does not collect, store, transmit, or share personal information.

PortKill is a local Windows utility that helps users identify and terminate processes using network ports on their device.

The application may access system process and network port information only to provide its core functionality. All processing happens locally on the user's device.

PortKill does not use analytics, advertising, tracking, or cloud services.

If future versions introduce online functionality, this policy will be updated.
